# Laghaim Original Analytics & Leaderboards

An automated web dashboard and scraper tracking player rankings, guild movements, level progression, and daily XP statistics for Laghaim Original - https://www.laghaim-original.com

## 🚀 Features
- **Interactive Dashboard**: Tabbed views with multi-select filtering, and responsive charts.
- **Summary Modals**: Modals for individual Characters, Guilds, and Class demographics.
- **Automated Data Scraping**: Scheduled Playwright workflows updating rolling 7-day XP history.

## 📊 Tech Stack
- **Frontend**: HTML5, Tailwind CSS, Chart.js, Lucide Icons
- **Automation**: Python, Playwright, Pandas, OpenPyXL, GitHub Actions
